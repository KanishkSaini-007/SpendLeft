# SpendLeft

What can I safely spend today, and still make it to next month?

**Live demo:** https://kanishksaini-007.github.io/SpendLeft/

## What it does

- Set your monthly allowance and the day it renews (default: the 1st).
- Log expenses as they happen (amount + a note).
- Shows what is left this cycle, and the number that matters: **safe to spend per day** - what is left divided by the days left, today included.
- A pace bar compares what you have spent against where you should be on this day of the cycle, and tells you plainly when you are running ahead of your money.
- Expenses are grouped by day, newest first, with one-tap delete.

## Why

My allowance does not run out on the 28th because of one big purchase. It dies by a hundred small ones around the 12th. This makes the daily number visible before it is a problem.

## Tech

Plain HTML, CSS and JavaScript in a single file. No frameworks, no build step, no account. Everything is stored in your browser's localStorage only.

## Run it

Open `index.html` in any browser, or visit the live demo above.
